# Live Sticky Notes

Editable Vite/React source reconstructed from the latest working deployment and preserved in GitHub.

## Features
- Facilitator and participant views
- Supabase Realtime
- QR join flow
- English / Arabic
- Four sticky note colors
- Drag, delete, clear, fullscreen
- QR-safe automatic note layout
- Color grouping
- Live common-word highlighting
- Find Similar
- Background image upload / change / remove on facilitator board
- Screenshot export of full notes board

## Run locally
```
npm install
npm run dev
```

## Deploy
Connect this repository to Vercel and deploy the `main` branch.

The current Supabase public client configuration is in `src/supabase.js`.

Git-connected deployment is enabled for the `main` branch.
